# 探槽样品区智能投影软件 V3.0

## 软件简介

根据样轨投影表数据，生成探槽平面图并导出AutoCAD DXF格式文件的工具软件。

**作者：消化** - 地质工作者

## 功能特性

- 读取样轨投影表Excel数据（V2版本输出）
- 实时预览探槽平面图
- 支持鼠标拖拽平移、滚轮缩放
- 支持设置样品厚度、比例尺
- 支持设置样品在左侧或右侧
- 支持设置探槽起点坐标
- 支持样品号标注显示/隐藏
- **导出标准AutoCAD DXF格式文件**
- **AB/CD线为完整多段线，可直接测量总长度**
- **导出时自动过滤非采样区，只显示样品区**

## 技术特点

- **共用边界法线计算**：相邻样品共享边界时使用统一的法线方向，确保边界完全重合
- **多段线(POLYLINE)输出**：探槽主线AB和壁线CD导出为完整多段线，便于长度测量
- **智能样品区过滤**：自动识别并排除非采样区，只导出真正的样品区域

## 安装依赖

```bash
pip install -r requirements.txt
```

依赖包括：
- Python 3.8+
- PyQt5
- openpyxl

## 使用方法

1. 运行软件：`python main.py`
2. 点击"打开Excel"按钮，选择样轨投影表文件
3. 在参数设置区调整比例尺、样品厚度、位置等参数
4. 在右侧预览区查看平面图效果
5. 点击"导出DXF"按钮输出文件

## 输入文件格式

Excel文件应包含以下列（由V2版本生成的样轨投影表）：

| 列名 | 说明 |
|------|------|
| 工程编号 | 探槽编号 |
| 导线号 | 导线段标识 |
| 方位 | 方位角 |
| 坡度 | 坡度角 |
| 样长 | 样品长度 |
| X | X坐标 |
| Y | Y坐标 |
| 样号 | 样品编号（H开头） |

## 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 比例尺 | 图面距离与实际距离的比值 | 1:1000 |
| 样品厚度 | 样品区域在图面上的宽度(毫米) | 2mm |
| 样品位置 | 样品显示在探槽的左侧还是右侧 | 左侧 |
| 起点坐标 | 探槽起点在DXF中的坐标位置 | (0, 0) |

## 输出DXF图层

| 图层 | 说明 | 颜色 |
|------|------|------|
| TRENCH | 探槽主线(AB) - 多段线 | 红色 |
| WALL | 探槽壁线(CD) - 多段线 | 洋红色 |
| SAMPLE | 样品矩形边框 | 黑白交替 |
| SAMPLE_FILL | 样品区域填充 | 黑白交替 |
| TEXT | 样品号标注 | 绿色 |
| MARKER | 起点标记 | 蓝色 |

## 鼠标操作

- **拖拽**：平移视图
- **滚轮**：缩放视图
- **右键菜单**：重置视图

## 快捷键

| 快捷键 | 功能 |
|-------|------|
| Ctrl+O | 打开Excel |
| Ctrl+S | 导出DXF文件 |
| Ctrl+Q | 退出 |
